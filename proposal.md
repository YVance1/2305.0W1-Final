# PySudoku

## Repository
https://github.com/YVance1/2305.0W1-Final

## Description
This project will be simple sudoku game that the user can solve. It is relevant because it is a game that many people are familiar with and play often, and it will give me good experience using basic skills such as creating interfaces and working with equations that are very basic and useful for any type of coding I will do in the future. I also really like sudoku so I can play my game in the future also. 

## Features
- Feature 1
	- generates random, solveable, sudoku board
- Feature 2
	- allow user to click on squares and fill in number based on square clicked
- Feature 3 
    - button that checks answers
- Feature 4
	- squares that have incorrect numbers will turn red when checked
- Feature 5 
    - celebration when all squares are filled in correctly 
- Feature 6
    - when a cell with a number is clicked, all numbers of that kind are highlighted blue
- Feature 7 
    - User cannot delete numbers given at start of game, but can replace/delete numbers they filled in

## Challenges
- I will have to figure out how to randomly generate the board in a state that is solveable.
- I will have to research how to control how many cells are filled in at the start of the game.

## Outcomes
Ideal Outcome:
- I end up with a running program that launches a randomly generated and solveable sudoku board that the user can input numbers into and check whether their answers are correct or incorrect. Cells with the same number as the number clicked on will be highlighted. incorrect cells will be highlighted red when the check button is pressed.

Minimal Viable Outcome:
- The program will run a sudoku game, not necessarily randomly generated and may be the same every time or cycle through a list of 2 or 3. The program will know when all filled in numbers are correct and will celebrate. The user will be able to delete their mistakes and replace them, but cannot replace starting numbers.
